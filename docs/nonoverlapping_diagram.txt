ASCII Diagram: Overlapping vs Nonoverlapping Domain Decomposition
=================================================================

1D Example with 4 elements and 2 subdomains
-------------------------------------------

MESH STRUCTURE:
Element:  |--1--|--2--|--3--|--4--|
Nodes:    1     2     3     4     5

METIS PARTITION (at element level):
Domain 1: Elements [1, 2]
Domain 2: Elements [3, 4]

┌─────────────────────────────────────────────────────────────────┐
│ OVERLAPPING MODE (default, nonoverlapping=false)               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Domain 1:  |====1====|====2====|====3====|                     │
│  Domain 2:              |====3====|====4====|====5====|         │
│                                                                 │
│  Nodes in Domain 1: [1, 2, 3]                                  │
│  Nodes in Domain 2: [3, 4, 5]                                  │
│  Intersection: [3]  ← Node 3 belongs to BOTH domains           │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ NONOVERLAPPING MODE (nonoverlapping=true)                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Domain 1:  |====1====|====2====|====3====|                     │
│  Domain 2:                          |====4====|====5====|       │
│                                                                 │
│  Nodes in Domain 1: [1, 2, 3]                                  │
│  Nodes in Domain 2: [4, 5]                                     │
│  Intersection: []  ← No shared nodes!                          │
│                                                                 │
│  Note: Node 3 is assigned to Domain 1 (first domain that       │
│        contains it). Domain 2 gets only nodes [4, 5].          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘


2D Example with 4 elements (2x2 grid) and 2 subdomains
-------------------------------------------------------

MESH STRUCTURE:
     1-----2-----3
     |  1  |  2  |
     4-----5-----6
     |  3  |  4  |
     7-----8-----9

Element 1: nodes [1, 2, 4, 5]
Element 2: nodes [2, 3, 5, 6]
Element 3: nodes [4, 5, 7, 8]
Element 4: nodes [5, 6, 8, 9]

METIS PARTITION:
Domain 1: Elements [1, 3]  (left column)
Domain 2: Elements [2, 4]  (right column)

┌─────────────────────────────────────────────────────────────────┐
│ OVERLAPPING MODE (default)                                     │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Domain 1 nodes: [1, 2, 4, 5, 7, 8]  (from elements 1, 3)     │
│  Domain 2 nodes: [2, 3, 5, 6, 8, 9]  (from elements 2, 4)     │
│                                                                 │
│  Intersection: [2, 5, 8]  ← Interface nodes belong to BOTH     │
│                                                                 │
│     D1    BOTH   D2                                            │
│     1-----2-----3                                              │
│     |     |     |                                              │
│     4-----5-----6                                              │
│     |     |     |                                              │
│     7-----8-----9                                              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ NONOVERLAPPING MODE                                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Domain 1 nodes: [1, 2, 4, 5, 7, 8]  (assigned first)         │
│  Domain 2 nodes: [3, 6, 9]           (only non-assigned)      │
│                                                                 │
│  Intersection: []  ← No shared nodes!                          │
│                                                                 │
│     D1    D1     D2                                            │
│     1-----2-----3                                              │
│     |     |     |                                              │
│     4-----5-----6                                              │
│     |     |     |                                              │
│     7-----8-----9                                              │
│                                                                 │
│  Note: Interface nodes [2, 5, 8] are assigned to Domain 1     │
│        (first domain that contains them). Domain 2 gets only   │
│        the nodes that weren't already assigned.                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

ALGORITHM:
==========

For each subdomain i (in order):
  1. Start with all nodes from elements in subdomain i
  2. If nonoverlapping=true:
     - Remove nodes already assigned to previous subdomains
     - Mark remaining nodes as assigned to subdomain i
  3. Convert nodes to DOFs

This ensures:
  ✓ No node appears in multiple subdomains
  ✓ All nodes are covered (assigned to exactly one subdomain)
  ✓ Interface nodes go to the first subdomain that contains them
